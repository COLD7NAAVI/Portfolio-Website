# Futuristic Cyberpunk Engineering Command Center — Portfolio

A high-tech, cinematic, and authentic personal portfolio built for an **Electronics & Communication Engineering (ECE) student, programmer, robotics developer, cybersecurity enthusiast, and AI experimenter**.

The website delivers an immersive dark cyberpunk command-center interface powered by an atmospheric background video (`assets/cyberpunk.mp4`) with dual-layer dark vignette and CRT scanline overlays. It strictly presents **100% truthful, verifiable technical accomplishments** with zero fabricated metrics or artificial corporate history.

## ⚡ Key Command Center Features

1. **Cinematic Atmospheric Background**:
   - `assets/cyberpunk.mp4` seamlessly loops in a GPU-accelerated background layer.
   - Dual contrast overlays (radial vignette + horizontal CRT scanlines) protect text contrast and guarantee WCAG AA legibility.

2. **Real-Time HUD Telemetry**:
   - Live local digital clock and dynamic status indicators.
   - Dynamic typewriter cycling through genuine engineering disciplines.

3. **Interactive Cybersecurity Terminal Simulator**:
   - Located in the Cyber Lab section.
   - Supports interactive terminal commands: `help`, `projects`, `skills`, `about`, `status`, `contact`, and `clear`.
   - Includes one-click command execution chips for mobile and quick browsing.

4. **Multi-Domain Filter Tabs**:
   - Instant filtering of technical skills and projects by category.

5. **Direct Comms Uplink**:
   - One-click email copying with cyber toast notifications.
   - Validated transmission form with interactive packet sending feedback.

## 📝 Customization Placeholders

When you are ready to insert your personal contact coordinates, open `index.html` and replace:

- `[Your Name Placeholder]` &rarr; Your full name
- `[your.email@example.com]` &rarr; Your real professional email address
- `https://github.com/[your-username]` &rarr; Your GitHub URL
- `https://linkedin.com/in/[your-profile]` &rarr; Your LinkedIn URL
- `[University / Institute Name Placeholder]` &rarr; Your university/college name
- `assets/resume.pdf` &rarr; Place your resume PDF inside `assets/` and link to it

## 🌐 Viewing the Website

Simply double-click `index.html` in your file browser or open it in any modern browser (Chrome, Firefox, Edge, Safari). Alternatively, run any local development server:

```powershell
# Optional: Python local HTTP server
python -m http.server 8000
```
Then visit `http://localhost:8000`.
